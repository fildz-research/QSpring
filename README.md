# QSpring: Mid-Air Printed Springs

![qspring](https://github.com/user-attachments/assets/ec73aeb2-89ae-409b-b7d3-6d371a59d495)

QSpring (QuasiSpring) explores mid-air printing combined with cold extrusion to produce springs that can stretch, contract, and bend as well as print object wireframes.
